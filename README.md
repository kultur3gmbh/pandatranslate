# pandatranslate
PandaTranslate — visual WordPress translation, language paths, switchers and builder elements.

## Version 0.6.0

Language-specific media, central text editing and literal gettext collection are available in the standalone base. DeepL joins the existing named Google APIs. Dynamic text uses only published, unambiguous, public-page dictionary entries; visitor content is not sent to an external API automatically.

Multilingual adds the expanded SEO integrations, translated taxonomy/CPT URL bases, static WooCommerce labels, order/session language and customer mail localization. Customer/order values are never translation inventory. Custom reusable email templates are collected before placeholder interpolation. Automatic SEO values remain drafts when automatic publication is disabled and can be reviewed in the post SEO box.

Media mappings are per page and image occurrence. Removing a mapping does not delete a media attachment. CSS background images are outside the media editor in this version. Installed WordPress/WooCommerce language packs are reused where available; this release does not install language packs automatically.

Existing TranslatePress migration remains available. WPML and Polylang are next, followed by Weglot; no new migration importer is included in 0.6.0.
